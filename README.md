# VOSC Activity 1 – Tic-Tac-Toe

## About

A simple two-player Tic-Tac-Toe game created as part of the VOSC Activity 1 prerequisite task. It runs entirely in the browser and works offline.

## Features

- 3×3 board with Player 1 = X and Player 2 = O
- Turns alternate automatically, and the current turn is always displayed
- Occupied cells cannot be overwritten
- Detects all 8 winning combinations and highlights the winning cells
- Detects a draw
- Game stops after a win or draw
- "Restart Game" button resets everything
- Responsive layout and keyboard-accessible buttons

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Download the repository as a ZIP (or run `git clone <repository-url>`).
2. Extract it if needed and open the `VOSC Activity-1` folder.
3. Double-click `index.html` to open it in any web browser. No internet or installation needed.

## How to Play

1. Player X starts.
2. Click an empty cell.
3. Players alternate turns.
4. Get three symbols in a row, column, or diagonal to win.
5. If all cells are filled without a winner, the game is a draw.
6. Click **Restart Game** to play again.
